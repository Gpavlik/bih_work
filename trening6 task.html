Робота з конкурентами

🟢 Пропишіть по 3 запитання з підложками для виявлення конкурентів

🟢 Для одного з конкурентів знайдіть 4 сегменти відйому (пригадайте табличку порівняння)

🟢 Придумайте 3 запитання для пошуку цих сегментів

🟢 Пропишіть аргументацію для відйому від конкурента по моделі ХПВ

🟢 Пропишіть 3 фрази для заміни конкурента
